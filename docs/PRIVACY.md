# 隐私说明

适用于浏览器扩展「GitHub 中文化」（Chrome、Edge、Firefox）。

## 处理的数据

| 数据       | 内容                                                                                 | 存放位置                                                                              |
| ---------- | ------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------- |
| 页面文字   | github.com、gist.github.com、www.githubstatus.com 页面上的界面文字，在本地替换为中文 | 不保存                                                                                |
| 设置       | 开关、排除路径、翻译语言、界面语言、外观                                             | `storage.sync`，可能随浏览器账号同步；界面语言与外观另缓存在扩展页面的 `localStorage` |
| 自定义词条 | 你添加的原文与译文                                                                   | `storage.local`                                                                       |
| 页面标记   | 翻译期间 `<html>` 上的 `data-gcn-i-<随机 id>` 属性，页面脚本可读取                   | 不保存，停用时移除                                                                    |

## 保留与删除

- 清除浏览数据不删除扩展存储。
- 卸载扩展时，浏览器删除 `storage.local` 中的全部数据。

## 网络请求

- 停用、排除当前页、进入排除路径、改自定义词条、改时间本地化开关时，若当前页是 Turbo 缓存副本、带有 GitHub 缓存写回的译文或残留的旧译文（如扩展更新后），重新请求当前 GitHub 页面；没有 Turbo 时整页重新加载。
- GitHub 从自身缓存写回带译文的标题或页面元素时（前进后退，或帧导航到带锚点的地址），若已停止翻译，或这些译文已过时（如之后改过自定义词条、时间本地化开关，或扩展更新过），重新请求当前 GitHub 页面。
- Chrome、Edge 中扩展更新、卸载或在浏览器中停用时，若当前页是 Turbo 缓存副本或带有 GitHub 缓存写回的译文，重新请求当前 GitHub 页面。
- 以上重新请求被帧导航打断，且旧译文仍在页面上时，再请求一次。
- 点弹出页「刷新」时重新加载当前页。
- 不发起其他网络请求。

## 不做的事

- 不向开发者或任何第三方发送数据。
- 不出售、不转让数据，不用于广告、信用评估或与翻译无关的用途。
